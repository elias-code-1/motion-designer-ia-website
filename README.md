# 🎬 Motion Designer IA — Landing Page & Showcase Studio

> Site web officiel et landing page haute conversion pour la formation **« Crée ton Studio Vidéo Motion Designer IA — Deviens libre grâce à l'IA ! »** par **APEDO Elias**.

---

## 🚀 À Propos

Cette landing page e-commerce présente la formation pratique pour créer des vidéos motion design professionnelles sans logiciel complexe, en utilisant des outils 100% gratuits et un simple navigateur web.

### 🛠️ Rôle des 4 Outils IA Enseignés
- **Claude** : Génère **toute la vidéo** de A à Z avec **tous les effets sonores (SFX)**, les animations fluides, la kinetic typography et les transitions cinématiques via le prompt master.
- **ElevenLabs** : Génère la **voix off ultra-réaliste**, naturelle et expressive sans accent robotique.
- **CapCut** : Sert à **synchroniser la voix off (VO) et la vidéo**, caler le rythme au millième de seconde et ajouter les sous-titres automatiques.
- **Navigateur Web** (Chrome, Brave, Edge) : Exécute et prévisualise l'ensemble directement en ligne (zéro logiciel lourd payant ni PC gamer requis).

## 📦 Installation & Démarrage

### 1. Prérequis
- [Node.js](https://nodejs.org/) (version 18 ou supérieure recommandée)
- npm, pnpm ou yarn

### 2. Cloner le projet
```bash
git clone https://github.com/elias-code-1/motion-designer-ia-website.git
cd motion-designer-ia-website
```

### 3. Installer les dépendances
```bash
npm install
```

### 4. Lancer le serveur de développement
```bash
npm run dev
```
Accède à `http://localhost:5173` dans ton navigateur.

### 5. Compiler pour la production
```bash
npm run build
```
Les fichiers optimisés et minifiés seront générés dans le dossier `dist/`.
